# 🃏 FreeCell Progresivo v2

**ES:** Solitario **FreeCell** con niveles progresivos de dificultad. Usa las celdas libres para organizar y mover las cartas hasta ordenar los cuatro palos.

**EN:** A **FreeCell** solitaire with progressive difficulty levels. Use the free cells to rearrange and move cards until all four suits are ordered.

## 🎮 Controles / Controls

| Acción / Action | Ratón / Mouse |
|:---|:---|
| Seleccionar / mover carta / Select / move card | Clic / Click |
| Pausa / Pause | `Esc` |

## ▶️ Cómo jugar / How to play

Abre **`freecell.html`** en tu navegador, pulsa **JUGAR** y avanza de nivel.

Open **`freecell.html`** in your browser, press **JUGAR** and progress level by level.
