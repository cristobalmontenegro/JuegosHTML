# 🌙 Moon Patrol Clone

**ES:** Recreación del arcade *Moon Patrol*. Conduce tu vehículo lunar, salta obstáculos y cráteres, y dispara a los ovnis enemigos.

**EN:** A recreation of the *Moon Patrol* arcade. Drive your lunar vehicle, jump over obstacles and craters, and shoot down enemy UFOs.

## 🎮 Controles / Controls

| Acción / Action | Tecla / Key |
|:---|:---|
| Conducir / Drive | `←` `→` |
| Disparar arriba / Fire up | `↑` |
| Disparar al frente / Fire forward | `Z` o `Ctrl` |
| Saltar / Jump | `Espacio` / `Space` |
| Pausa / Pause | `Esc` |
| Empezar / Start | `Espacio` o `Enter` |

## ▶️ Cómo jugar / How to play

Abre **`moon_patrol.html`** en tu navegador.

Open **`moon_patrol.html`** in your browser.
