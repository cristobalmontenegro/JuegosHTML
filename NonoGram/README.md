# 🧩 Nonogramas — El Desafío

**ES:** Puzzle de lógica tipo **Nonograma / Picross**. Usa los números de cada fila y columna para descubrir la imagen oculta.

**EN:** A **Nonogram / Picross** logic puzzle. Use the row and column numbers to reveal the hidden picture.

## 🎮 Controles / Controls

| Acción / Action | Ratón / Mouse |
|:---|:---|
| Pintar / alternar / Paint / toggle | Clic izquierdo / Left click |
| Marcar con una X / Mark with an X | Clic derecho / Right click |
| Arrastrar para pintar varias / Drag to paint many | Clic sostenido |
| Pausa / Pause | `Esc` |

En el juego puedes **Verificar la solución**, **Rendirte** o ver los **mejores puntajes**. / In-game you can **Check the solution**, **Give up** or view the **high scores**.

## ▶️ Cómo jugar / How to play

Abre **`index.html`** en tu navegador.

Open **`index.html`** in your browser.
