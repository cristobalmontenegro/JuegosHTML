# 🎮 JuegosHTML

**ES:** Colección de juegos clásicos y experimentos hechos con HTML, CSS y JavaScript puro (sin frameworks), pensados para ejecutarse directamente en el navegador. Solo abre el `index.html` de cada carpeta.

**EN:** A collection of classic games and experiments built with plain HTML, CSS and JavaScript (no frameworks), meant to run straight in the browser. Just open each folder's `index.html`.

## 🚀 Cómo jugar / How to play

**ES:** Clona el repositorio y abre en tu navegador el archivo `index.html` (o `.html`) de la carpeta del juego que quieras. No requiere instalación ni servidor.

**EN:** Clone the repository and open the game folder's `index.html` (or `.html`) in your browser. No installation or server required.

```bash
git clone https://github.com/cristobalmontenegro/JuegosHTML.git
cd JuegosHTML
# Luego abre, por ejemplo: SpaceInvaders/index.html
```

## 🛠 Tecnologías / Technologies

- **HTML5** — estructura y `<canvas>` cuando aplica
- **CSS3** — estilos y animaciones
- **JavaScript** (vanilla) — lógica de juego, sin dependencias externas
