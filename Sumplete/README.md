# ➕ Sumplete Challenge Pro v3

**ES:** Puzzle de sumas tipo *Sumplete*. Elimina números de la cuadrícula hasta que la suma de cada fila y cada columna coincida con su objetivo.

**EN:** A *Sumplete*-style sum puzzle. Remove numbers from the grid until every row and column adds up to its target.

## 🎮 Controles / Controls

| Acción / Action | Ratón / Mouse |
|:---|:---|
| Eliminar / restaurar celda / Remove / restore cell | Clic en la celda / Click the cell |

### Botones del juego / In-game buttons

- **Nueva Partida** / New Game
- **Deshacer** / Undo
- **¿Tip?** (cuesta 50 puntos) / Tip (−50 pts)
- **Siguiente Nivel** / Next Level

## ▶️ Cómo jugar / How to play

Abre **`sumplete.html`** en tu navegador.

Open **`sumplete.html`** in your browser.
