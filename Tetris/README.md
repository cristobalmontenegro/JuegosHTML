# 🧱 Polyomino Cascade (Tetris)

**ES:** Tetris con inicio suave (*slow start*), pausa y tabla de mejores puntajes. Encaja las piezas para completar líneas.

**EN:** A Tetris with a slow start, pause and a high-score leaderboard. Fit the pieces to clear lines.

## 🎮 Controles / Controls

| Acción / Action | Tecla / Key |
|:---|:---|
| Mover / Move | `←` `→` |
| Rotar / Rotate | `↑` |
| Bajar rápido / Soft drop | `↓` |
| Pausa / Pause | `Esc` |

Al empezar, escribe tus **iniciales** para registrar tu puntaje. / On start, type your **initials** to record your score.

## ▶️ Cómo jugar / How to play

Abre **`tetris.html`** en tu navegador.

Open **`tetris.html`** in your browser.
